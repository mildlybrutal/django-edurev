# Project Instructions

Read @AGENTS.md before making changes.

## Rules
- Follow the P06 project specification.
- Backend: Django + DRF + PostgreSQL.
- Frontend: Next.js + TypeScript + Tailwind CSS.
- Use Celery + Redis for background processing.
- Eligibility and readiness must remain separate.
- External coding activity is evidence, not automatic proof of expertise.
- Do not invent requirements or claim unimplemented features work.
- Do not hardcode demo metrics as real data.
- Write tests for business logic and authorization.
- Never expose recruiter data outside its approved drive.
- Do not add dependencies without a clear reason.
- Do not commit secrets or real student data.
- Run relevant tests and report their actual results.
- Work in small, reviewable increments.
